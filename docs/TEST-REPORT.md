## 자동 검증 — 통과

`npm test` 22/22 통과 (`node --test tests/*.test.mjs`):

- EPUB 콘텐츠 격리: CSP 부여, 실행 가능/외부 콘텐츠 차단, 안전하지 않은 CSS
  import·외부 URL 제거, 주입 지점 없는 손상된 HTML 미렌더링
- 환경설정: 숫자 값 클램프, 폐기된 폰트 자동 이관
- 백업: 레거시 백업 정규화, 알 수 없는 폰트·안전하지 않은 ID·중복·잘못된
  날짜 거부
- 버전 일관성: 런타임 버전·백업 버전·`package.json` 버전 정렬
- 배포: GitHub Pages 소유자를 배포 hostname에서 계산, Service Worker
  캐시 정리가 Petal 스코프로 한정, 배포 워크플로가 명시적 runtime
  allowlist를 사용, 공개 문서가 현재 릴리즈·Actions 설정과 일치
- UI 계약: 서재 헤더에 Settings 진입점이 하나이고 Journal이 그 안에 있음
- 독서 세션: 승인된 진행률·도서 필드만 포함, 자정을 넘는 세션이 날짜별
  레코드로 안정적으로 분리, 숨김 시간 제외·유휴 시간 5분 상한 적용
- 하이라이트/북마크/저널 투영: 요청된 텍스트는 유지하되 비공개 CFI·원본
  위치 식별자는 제외, 콘텐츠 끄기 시 독서 텍스트 미노출, 저널 리댁션이
  안정적 식별자·타이밍은 유지한 채 독서 텍스트만 제거
- 모든 실제 Petal 변경·라이프사이클 경로 배선 확인

## 첫 시작 데이터 초기화 (fresh-start reset)

첫 릴리즈로 정리하면서 기존 `resetAllLocalData()`를 이용해 첫 실행 시
로컬에 남아 있을 수 있는 이전 테스트 데이터(서재·백업·환경설정·독서
세션 등)를 초기화하는 fresh-start 동작을 추가했습니다. 사용자가 실제로
새 기기·새 브라우저 프로필에서 처음 여는 것과 동일한 빈 상태로
시작합니다. 관련 회귀 테스트(백업 유효성, 환경설정 이관 등)는 위 22개
테스트에 포함되어 통과했습니다.

  뜨는지 육안 확인
